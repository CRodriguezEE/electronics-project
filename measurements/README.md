# Measurements

This folder contains oscilloscope captures and bench-test evidence from the single-phase MOSFET H-bridge inverter validation.

## Included Measurements

| File | Description |
|---|---|
| `spwm_frequency_16_97khz.jpeg` | Oscilloscope capture showing measured SPWM switching frequency of 16.97 kHz |
| `final_bench_setup_12v.jpeg` | Final bench setup showing 12 V DC bus validation with oscilloscope output during inverter testing |

## Notes

- Measurement images are used as validation evidence for switching behavior and observed filtered-output behavior.
- THD and output power rating were not formally characterized during this validation stage.
